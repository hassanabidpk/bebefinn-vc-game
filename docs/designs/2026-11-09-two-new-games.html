1. Two new learning skills

The latest code already includes eight coloring pictures, 12 crayons, real feed foods, and themed Match boards. These additions introduce sequencing and spatial language alongside the existing alphabet, counting, matching, and shape games.

2. Bubble Patterns

A quiet observation game. The sequence stays visible, every symbol has its own shape, and the child can ask for a hint at any time.

Choice state · one repeated pair is bracketed for younger players. The yellow bubble is the destination; tray objects retain distinct silhouettes.

3. Little Reef Builder

Learn above, below, inside, and beside by placing friends in an original reef. A tiny picture instruction makes the task understandable with speech muted.

Guided first step · tap the fish, then the upper landing pad. Pads share a neutral shape, so placement teaches position rather than outline matching.

See and hearOne relation at a time.
PlaceTap → tap; optional drag.
Bring it to lifeFour placements finish a reef.

Three authored scenes: Sunny Reef, Shell Cove, and Kelp Garden. Inside targets keep the whole friend visible. Beside offers one eligible side so an equally valid mirror placement is never rejected.

Gentle correction models the destination. Replay resets placements but keeps earned reef tiles. Every accepted placement saves before the celebration, so a reload can resume safely.

4. Build and validation plan

Build Bubble Patterns first

It has the smaller input surface and establishes shared sea symbols, localized messages, and guarded progress storage. Reef Builder can then reuse those pieces and the existing Shape Sort transform helpers.

Shared product rules

  • English labels and narration.
  • At least 64px targets after frame scaling.
  • Silent, keyboard, touch, and reduced-motion play.
  • Progress on device; no accounts or telemetry.
  • No new paid audio or image generation.

Before shipping

  • Validate every authored puzzle.
  • Test duplicate input and stale callbacks.
  • Test reload, replay, corrupt/blocked storage.
  • Verify 360×800, 800×360, and tablet layouts.
  • Run browser and real-device touch QA.

Integration boundary

Add lazy-loaded patterns and builder modes. Keep current lessons and sticker payloads intact; each game owns its own versioned device save. New narration uses a typed English message catalog, with browser speech as the baseline.

Home needs two additional chips. Validate all 14 entries remain visible and tappable. If they do not fit, use two pages of seven chips with a large Next control; any game stays within two taps. Preserve the Start action and sticker-book access.
